# Bobby's Dev Hub

I want to create a premium, responsive dark-mode personal portfolio for Bobby Chilami, positioned as “Software Engineer | Backend & AI Engineer”. It should include sticky navigation (Home, About, Experience, Projects, Skills, Achievements, Writing, Contact) plus GitHub, LinkedIn and Resume actions; a concise hero with the provided headline, supporting copy, technology badges and configurable availability status; and an About section with Backend Engineering, AI Engineering and Technical Leadership highlights. Use clean typography, strong spacing, subtle borders, accessible contrast, restrained animations, reusable components and recruiter-friendly UX. Do not fabricate any personal, employment, technology or achievement information.
